### 🧑‍💻 About me

- 🔭 Currently building **[idtp](https://github.com/Oscar-Heredia/idtp)** — a Python tool that fills existing PowerPoint templates with document content, measuring how much text fits in each slot beforehand (fontTools).
- 💻 I build **web applications end to end**: REST APIs with authentication, responsive frontends, and the tooling around them.
- 🌱 Also hands-on with **IoT**: designed and built a tech-enabled greenhouse with C++ and microcontrollers.
- 📫 Reach me at **weroskidev@gmail.com**
